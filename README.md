# ESP32-S3 Blink Button Reisters

Проєкт демонструє керування GPIO через регістри, реалізацію неблокувального миготіння світлодіода та перемикання між двома режимами роботи за допомогою кнопки.

## Реалізований функціонал
- LED Blinking: періодичне вмикання та вимикання світлодіода.
- Two Blink Modes: два режими миготіння — повільний (1 Гц) і швидкий (5 Гц).
- Button Control: перемикання між режимами за допомогою кнопки.
- GPIO Register Access: керування станом світлодіода та читання стану кнопки через GPIO-регістри.
- Software Debouncing: програмне усунення брязкоту контактів кнопки.
- Non-blocking Timing: використання esp_timer для контролю часу без блокувальних затримок у логіці миготіння.
