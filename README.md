# ESP32-S3 PWM Control — LED & DC Motor

Проєкт на ESP32-S3 та ESP-IDF, у якому реалізовано керування яскравістю світлодіода та швидкістю DC-мотора за допомогою PWM.

Що реалізовано:
- Потенціометр підключений через ADC.
- Потенціометр керує значенням PWM.
- У режимі LED PWM регулює яскравість світлодіода.
- У режимі Motor PWM регулює швидкість DC-мотора.
- Кнопка перемикає режими керування.
- DC-мотор керується через транзистор ST2N2222A (NPN).
- Для захисту транзистора використовується flyback diode.
- Реалізовано спільну землю між ESP32 та живленням мотора.
