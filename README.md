# Усунення брязкоту контактів на фреймворку ESP-IDF
Реалізовано обробку натискання кнопки на ESP32-S3 за допомогою ESP-IDF.

- GPIO18 використовується як вхід
- реалізовано debounce 50 мс
- використано state machine: STATE_IDLE та STATE_DEBOUNCE
- підраховується кількість натискань
- результат виводиться через ESP_LOGI()
- для вимірювання часу використовується esp_timer_get_time()
