# Мініпроект. Читання даних з Терморезистора
У проєкті реалізовано вимірювання температури за допомогою NTC-термістора 10 кОм B3950, підключеного до ESP32 через подільник напруги. Значення напруги зчитується через АЦП ESP32 на GPIO4.

На основі виміряної напруги розраховується опір термістора, після чого за Beta-формулою визначається температура в градусах Цельсія.

У програмі реалізовано:
- зчитування RAW-значення 12-бітного АЦП;
- отримання каліброваної напруги через analogReadMilliVolts();
- розрахунок опору NTC;
- розрахунок температури за коефіцієнтом B = 3950;
- виведення RAW, напруги, опору та температури через Serial Monitor.
