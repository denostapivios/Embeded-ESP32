# UART Communication — ESP32-S3

У цьому проєкті реалізовано UART-комунікацію між **ESP32-S3 та STM32F401**.

ESP32 може передавати команду STM32 для керування LED, а також приймати команду від STM32 для керування власним LED.

## Реалізовано

- UART-зв'язок з **STM32F401**.
- Передачу та прийом даних через UART.
- Передачу ASCII-команди `'1'` → STM32.
- Прийом ASCII-команди `'2'` ← STM32.
- Керування LED через UART-команди.
- Обробку натискання кнопки через GPIO interrupt.
- Debounce кнопки.
- UART-конфігурацію **115200, 8N1**.

## Принцип роботи

### ESP32 → STM32

При натисканні кнопки на ESP32:

```text
ESP32 Button
     ↓
UART: '1'
     ↓
STM32
     ↓
Toggle Yellow LED

```
