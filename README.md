# Дослідження брязкоту контактів кнопки за допомогою логічного аналізатора та мікроконтролера
- Натиснув кнопку 10 разів
- Логічним аналізатором записав форму сигналу кожного натискання
- Для кожного натискання визначив кількість, скільки імпульсів брязкоту виникло насправді та їх тривалість
- Написав код який рахує імпульси (зміни стану)

**Результат:**

Кількість імпульсів програмно відрізняється від того що показав аналізатор.
