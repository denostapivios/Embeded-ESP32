# ESP32-S3 — Неблокуючий аудіоплеєр для зумера

Реалізував неблокуючий аудіоплеєр на ESP32-S3 з використанням ESP-IDF.

Що зроблено:
- Генерація звуку через LEDC PWM
- Зміна частоти PWM для відтворення різних нот
- Реалізація фіксованого 50 мс тайм-тіку через апаратний GPTimer
- Використання ISR для формування події таймера
- Підтримка тривалості нот та пауз
- Неблокуюче виконання без delay() та vTaskDelay()
- Використання 25% duty cycle для зменшення різкості звучання зумера
