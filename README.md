# ESP32-S3 Potentiometer Servo Control

Керування сервоприводом SG90 за допомогою потенціометра на ESP32-S3 з використанням ESP-IDF.

Реалізовано:
- Зчитування потенціометра через ADC1 / GPIO4.
- Усереднення 16 ADC-вимірювань для зменшення шуму.
- Перетворення ADC-значення у кут потенціометра 0–270°.
- Пропорційне керування SG90 у діапазоні 0–180°.
- Обмеження діапазону потенціометра до діапазону сервоприводу.
- Генерація PWM через LEDC / GPIO5 з частотою 50 Hz.
- Керування SG90 через імпульси 500–2400 µs.
- Виведення поточного ADC-значення та кута відхилення в Serial Monitor

Поворот потенціометра керує положенням SG90 пропорційно: 0–180° потенціометра → 0–180° сервоприводу, а залишок діапазону потенціометра не використовується
