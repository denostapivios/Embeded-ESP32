# Два світлодіоди, зовнішня кнопка та BOOT
Реалізувати два режими миготіння світлодіодів в залежності від кнопки яка натиснута

- Під’єднав два світлодіоди та зовнішню кнопку до GPIO
- Використав кнопку BOOT (GPIO0) як другу кнопку без додаткового підключення
- Реалізував два режими миготіння світлодіодів:
   1. Режим, що активується зовнішньою кнопкою
   2. Режим, що активується кнопкою BOOT
- При натисканні зовнішньої кнопки перемикав LEDs у швидший режим миготіння.
- При натисканні кнопки BOOT перемикав LEDs у повільніший режим миготіння.
- Миготіння та брязкіт контактів кнопок реалізував через delay(), **така була умова завдання**.
