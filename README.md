# Переписано класичну логіку керування LED у стилі Embedded C++
- створено enum class LedState для опису станів LED (On / Off);
- створено клас Led, який інкапсулює роботу з конкретним GPIO-піном;
- додано метод init() для налаштування піна як OUTPUT та початкового вимкнення LED;
- додано метод set(LedState state) для керування станом світлодіода;
- GPIO-піни та інтервал перемикання винесено в constexpr;
- реалізовано почергове блимання червоного та синього LED через enum class BlinkPhase;
- замість блокуючого delay() використано millis(), завдяки чому логіка працює у неблокуючому режимі superloop;
- стан блимання та час попереднього перемикання зберігаються у локальних static змінних всередині loop();
- усунуто використання змінюваних глобальних змінних для керування станом програми.

У результаті отримано неблокуючу та більш структуровану реалізацію керування LED із використанням базових принципів Embedded C++.
