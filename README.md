# Калібрування даних з ADC (ESP-IDF)

У цьому завданні досліджується робота 12-бітного АЦП ESP32-S3 та вплив калібрування на точність вимірювання напруги.

Для формування змінної вхідної напруги використовується потенціометр, підключений між 3.3 V та GND. Середній контакт потенціометра підключений до ADC-входу GPIO4.

Програма періодично зчитує сире значення ADC (`RAW`) та виконує два способи визначення напруги:

- **U_manual** — напруга, розрахована вручну на основі значення `RAW`, розрядності ADC та максимального діапазону 3.3 V;
- **U_cali** — напруга, отримана за допомогою вбудованого механізму калібрування ADC в ESP-IDF.

Після цього для кожного вимірювання розраховується відносна похибка між ручним та каліброваним значеннями.

Мета завдання — порівняти результати двох методів та на практиці оцінити вплив калібрування ADC на точність вимірювання напруги.

Результати показали, що калібрування дозволяє отримувати точніші значення, а похибка ручного розрахунку змінюється залежно від рівня вхідної напруги.
