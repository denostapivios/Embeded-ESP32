# АЦП. Читання даних з Фоторезистора(LDR)
- Підключив LDR до ESP32 у вигляді подільника напруги.
- Зчитую значення АЦП кожні 1000 мс.
- Зчитую значення з АЦП за допомогою analogRead() (RAW data).
- Зчитую напругу за допомогою analogReadMillivolts().
- Виводжу в серійну консоль:
  1. RAW значення АЦП
  2. Обчислену напругу
  3. Напругу, виміряну analogReadMillivolts()
- Порівняв обидва значення напруги та обчислив похибку.
