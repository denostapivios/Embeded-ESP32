# ESP32 PID Регулятор

Проєкт реалізує систему автоматичного регулювання яскравості вбудованого RGB LED на базі ESP32 із використанням PID-регулятора та фототранзистора для зворотного зв’язку.

## Реалізований функціонал
- Керування вбудованим RGB LED через NeoPixel.

- Зчитування аналогового сигналу фототранзистора за допомогою ADC.

- Усереднення показників ADC для зменшення впливу шуму.

- Реалізація PID-регулятора з пропорційною, інтегральною та диференціальною складовими.

- Автоматичне коригування яскравості LED відповідно до заданого рівня освітленості.

- Обмеження вихідного значення яскравості в діапазоні 0–255.

- Обмеження швидкості зміни яскравості для плавнішого регулювання.

- Виведення поточних показників ADC, похибки, складових PID та PWM у Serial Monitor.

## Принцип роботи
1. Фототранзистор вимірює інтенсивність світла від RGB LED.

2. ESP32-S3 зчитує аналогове значення через ADC.

3. PID-регулятор обчислює різницю між заданим і поточним значеннями.

4. На основі похибки розраховується необхідна зміна яскравості LED.

5. Яскравість коригується, а процес вимірювання повторюється циклічно.
