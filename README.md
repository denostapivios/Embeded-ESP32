# Поліцейська мигалка
**Створивив програму яка імітує роботу поліцейської мигалки.**
- Використав два GPIO-виводи ESP32
- Під’єднав червоний та синій світлодіоди через резистори 220 Ом
- Реалізував послідовність миготіння, у якій червоний і синій LED блимають по черзі
