# ESP32-S3 SSD1306 OLED Display

Виведення тексту на OLED-дисплей SSD1306 128×64 через I²C на ESP32-S3 з використанням ESP-IDF.

Реалізовано:

- Ініціалізацію I²C на GPIO1 (SDA) та GPIO2 (SCL).
- Роботу з OLED SSD1306 через I²C на швидкості 400 кГц.
- Ініціалізацію дисплея через `esp_lcd`.
- Власний framebuffer розміром 1024 байти.
- Таблицю шрифту 5×8 для виведення тексту.
- Масштабування символів у 2× для більшого відображення.
- Очищення framebuffer перед виведенням.
- Виведення тексту `BeetRoot` на OLED-дисплей.
- Передачу framebuffer на дисплей для оновлення зображення.

Текст виводиться на дисплей через власний драйвер SSD1306 з використанням `esp_lcd_panel_draw_bitmap()`.
