# Датчик світла на базі LDR та ESP32-S3 з фільтрацією за методом ковзного середнього (SMA) та гістерезисом

Реалізував систему автоматичного керування LED залежно від рівня освітленості за допомогою LDR та ADC на ESP32-S3.

- Підключив LDR через подільник напруги.
- Налаштував ADC One-shot mode для періодичного зчитування аналогового сигналу.
- Реалізував Circular Buffer для зберігання останніх вимірювань.
- Реалізував Simple Moving Average (SMA) для фільтрації шуму ADC.
- Використав оптимізований підхід із підтримкою поточної sum, без повторного підсумовування всього буфера.
- Реалізував керування LED через enum-based state machine.
- Додав hysteresis з двома порогами для запобігання мерехтінню LED.

**Висновок:**
У результаті реалізував стабільне автоматичне керування LED за рівнем освітленості. SMA зменшує вплив шуму ADC, а hysteresis запобігає постійному перемиканню LED біля порогового значення.
