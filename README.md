# Safe Encoder(ESP32) — Cross-Platform Embedded Architecture

Навчальний embedded-проєкт цифрового сейфа з керуванням через rotary encoder та кнопкою. Основний акцент проєкту — побудова модульної архітектури з чітким розділенням платформо-незалежної логіки та платформо-залежної реалізації периферії.

Реалізовано:

- Зміна поточної цифри за напрямком обертання;
- Підтвердження цифри кнопкою;
- Перевірка введеного коду;
- Стани LOCKED / UNLOCKED;
- Автоматичне скидання при неправильному коді;
- Логування поточного стану та введеного коду;
- Окремий application layer з бізнес-логікою сейфа;
- Hardware interfaces для енкодера та кнопки;
- Окремий ESP32 BSP з реалізацією периферії через ESP-IDF;
- Типізація даних для взаємодії між рівнями архітектури;
- Підготовка структури для подальшого перенесення на STM32 без зміни бізнес-логіки.
